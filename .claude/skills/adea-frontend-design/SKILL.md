# AdeA frontend design
Read AGENTS.md, docs/15-frontend-design-engineering.md and the relevant module spec. Ask for the primary user task, current behavior and target if missing. Keep existing business rules and authorization unchanged. Use synthetic data here.
Choose one direction: Precision Light, Operations Dark or Enterprise Compact. Specify tokens, hierarchy, reusable components, table density, keyboard flows, responsive behavior and empty/loading/error/permission states before coding.
Use approved frontend-design or UI/UX Pro Max for direction; apple-design/emil-design-eng for purposeful motion only; Impeccable or web-design-guidelines for critique if installed and authorized. Do not install third-party skills or run hooks automatically. Do not claim external skills executed if unavailable.
Implement a small vertical slice, maintain accessible semantic markup, focus, reduced motion, contrast and clear status text. Test at 360/768/1440, keyboard, filters, empty/error states and primary task. Use Playwright/axe if available. Capture before/after evidence, report actual test results and unresolved issues. No secrets, internal screenshots, real UNC or private client data in public repo.
