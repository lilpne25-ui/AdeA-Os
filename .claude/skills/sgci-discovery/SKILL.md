# sgci-discovery
Read docs/00a-sgci-full-discovery-plan.md and prompts/SGCI-MASTER-PROMPT.md. Confirm scope, permissions and metadata-only first pass. For synthetic tests, define inventory schema, checkpoints, errors and reconciled denominator. For rule mapping, record doc ID, version, section, condition, action, exceptions and validation. Do not read actual UNC or external data here. Output coverage, exclusions, evidence, questions and next gate.
