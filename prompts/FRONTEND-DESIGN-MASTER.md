# Prompt maestro — Frontend Design Engineering
Actúa como diseñador de producto empresarial, frontend engineer senior y especialista en accesibilidad. Lee AGENTS.md, docs/01-architecture.md, docs/15-frontend-design-engineering.md y la Skill adea-frontend-design. Evalúa las Skills externas aprobadas: Anthropic frontend-design para dirección, Apple Design y Emil Design Engineering para interacciones, UI/UX Pro Max para patrones, Impeccable y Vercel guidelines para revisión. No instales nada sin aprobación ni simules que una Skill se ejecutó.
Antes de implementar, identifica rol, objetivo, tareas, reglas, permisos, estados, restricciones de rendimiento y plataforma. Si no existe UI, presenta tres direcciones visuales comparables con el mismo contenido: Precision Light, Operations Dark y Enterprise Compact. Usa datos sintéticos. No copies marcas o recursos de Apple. Pide una decisión de estilo antes de convertirlo en interfaz de producción.
Implementa únicamente el flujo seleccionado con componentes reutilizables, React/TypeScript si autorizado, tokens, diseño responsive, navegación, búsqueda, filtros, detalle, manejo de carga/error/vacío, foco y teclado. No sacrifiques densidad de tablas ni trazabilidad por estética. No inventes endpoints; marca toda simulación.
Aplica animaciones funcionales y reduced motion. Audita contraste, navegación, nombres accesibles y estados. Ejecuta Playwright/axe si disponibles, compara capturas a 360/768/1440, y entrega pruebas reales, problemas y coste. Conserva alcance, reglas y seguridad. No conectar sistemas reales ni desplegar sin autorización.
