# Prompt — diseñar Skills y subagentes
Lee AGENTS.md, CLAUDE.md y la documentación oficial https://code.claude.com/docs/en/skills y https://code.claude.com/docs/en/sub-agents . Entrevístame sobre una tarea repetitiva concreta: disparador, entradas, salidas, pasos, excepciones, herramientas, riesgos, ejemplos correctos y pruebas. Si solo es una pregunta simple, no crear agente.
Diseña primero una Skill pequeña con name, description precisa y SKILL.md; coloca detalles voluminosos en referencias opcionales. Define precondiciones, procedimiento, formato de salida, qué no hacer y criterios verificables. No incorporar secretos ni contenido restringido. Crea ejemplos sintéticos, prueba activación correcta, no activación fuera de alcance, salidas incorrectas y casos límite.
Solo crea subagente si requiere contexto aislado o revisión independiente; define name, description, herramientas mínimas y modelo inherit. Para auditoría usar Read, Glob, Grep; sin escrituras ni shell. Los permisos efectivos se controlan también en el entorno. No añadir bypassPermissions ni MCP no autorizado. Evalúa coste y comparación con agente único. Entrega archivos, prueba de uso, evidencia, limitaciones y propuesta de mejora; no afirmar que se cargaron si no se comprobó en Claude Code.
