# AdeA Intelligence OS — instrucciones compartidas
Proyecto conceptual público. Leer README y documentos pertinentes antes de trabajar. No contiene ni debe recibir datos reales, rutas UNC, credenciales, documentos internos, tickets privados o información personal. Trabajar únicamente con datos sintéticos aquí.
- Identificar objetivo, alcance, evidencia, supuestos, riesgo, coste y pruebas. Si faltan datos, preguntar lo indispensable; avanzar con pruebas sintéticas sin inventar.
- Preferir código determinista local, Python aprobado, cambios pequeños y revisables, pytest, lint y documentación. No instalar dependencias ni gastar sin autorización.
- No acceder a red interna, producción, rutas UNC o proveedores con datos reales sin aprobación institucional. No eludir permisos, seguir enlaces externos, ejecutar contenido documental ni compartir secretos.
- Para SGCI usar prompts/SGCI-MASTER-PROMPT.md y docs/00a-sgci-full-discovery-plan.md. 500 archivos es piloto, no límite final. Registrar cobertura y fallos.
- Para planificación de capacidad consultar docs/12-ai-engineering-cell.md; para capacitación docs/13-claude-academy-enablement.md.
- Skills son procedimientos reutilizables; agentes son contextos especializados. Usar una Skill antes de delegar; solo delegar tareas independientes cuando aporte valor y no abrir múltiples agentes por defecto (presupuesto limitado).
- Reportar archivos cambiados, pruebas realmente ejecutadas, limitaciones y siguiente decisión. No afirmar éxito no observado. No hacer commits/push/despliegues sin autorización para esa tarea.
