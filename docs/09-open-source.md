Claude Code y Codex son herramientas comerciales de desarrollo asistido, no se clasifican como open source. Revisar precios y modalidad de uso corporativo; no asumir que suscripciones permiten consumo API ilimitado. Algunos proyectos tienen ediciones o recetas comerciales, AGPL/GPL o licencias específicas (por ejemplo PM4Py, Neo4j, recetas OpenRewrite, modelos de inferencia). Evaluación de licencia por versión y modo de despliegue antes de combinar componentes. REA se considera candidato experimental, no garantía de decompilación ni de paridad.
