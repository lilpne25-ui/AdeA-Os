Especialización posterior: Building with the Claude API (9 h, RAG, agentes, tool use y MCP); MCP Advanced (1.5 h); Claude Platform 101 (1.5 h). Complementar con Python local 8–12 h de práctica, Git, pruebas pytest y manejo seguro de datos. Ruta común 12.5 h + laboratorio 8 h = 20.5 h por persona, distribuida 4 semanas, no sumarla dos veces a reserva de coordinación. Para 3 personas son 61.5 horas agregadas; dentro de reserva de 144 h del escenario preferido, no cabe íntegra en reserva de 48 h del mínimo; reducir ruta o reestimar.

## Evidencias
Semana 1: Claude Code 101, Fluency parcial, CLI y Git; ejercicio sintético. Semana 2: Skills, subagents, SDLC; crear un Skill y probarlo. Semana 3: MCP y evals; diseñar herramienta de lectura simulada, pruebas de permisos y casos límite. Semana 4: completar Fluency y equipo humano-agente, demo de scanner con pruebas. Registrar versión de curso, duración real, evaluación, evidencia, revisión y fecha; no afirmar certificación ni cursos impartidos sin respaldo. La formación interna no reproduce materiales propietarios; enlaza recursos oficiales y añade laboratorios propios.
