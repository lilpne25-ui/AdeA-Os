# Gobierno, seguridad y backlog
Propuesta no aprobada. Este repositorio público no debe contener información interna de clientes, documentos privados, datos personales, secretos, fragmentos de código no autorizados ni metodologías de terceros restringidas. Usar repositorio corporativo privado aprobado para implementación real. Revisar estándares internos sin publicar su contenido.

Controles: SSO, permisos mínimos por usuario/cliente, aislamiento, auditoría, cifrado, gestión de secretos, retención y borrado, backup/restore, revisión de proveedores de IA, pruebas de recuperación de información y prompt injection, análisis de dependencias, supervisión humana, control de cambios y rollback. Agentes no ejecutan cambios en producción ni envían comunicaciones a clientes sin aprobación. No indexar chats privados. No utilizar mapas de competencias como vigilancia o evaluación automatizada de empleados.
